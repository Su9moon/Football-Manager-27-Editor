# Football Manager 27 Editor — 简体中文说明

这是 FM27 Editor 的简体中文使用说明。程序支持 Windows 10/11 x64，可直接运行独立版 `Fm27Editor.exe`，无需单独安装 .NET。

## 当前中文状态

1.5.7 首次加入简体中文界面。设置中可在 English、Tiếng Việt 和简体中文之间切换，选择会保存在本机。

当前为**首批核心界面翻译**：常用导航、搜索、设置、球员与俱乐部常用字段、编辑操作及部分工具已有中文；尚未覆盖的专业字段、少见提示和部分游戏术语会继续显示英文。不会用不准确的中文猜译游戏数据字段。

## 安装位置与运行方式

这是免安装的 Windows x64 独立程序，不需要放进 Steam 的 FM27 安装目录，也不需要单独安装 .NET。建议将下载的 `Fm27Editor.exe` 放在固定目录，例如 `D:\Games\FM27Editor\Fm27Editor.exe`；也可以放在其他普通文件夹。不要放进 FM27 的游戏目录或 Steam 库目录。

程序设置和日志默认保存在 `%LOCALAPPDATA%\Fm27Editor\`（通常对应 `C:\Users\<用户名>\AppData\Local\Fm27Editor\`），不会把配置写入游戏安装目录。

1. 启动 Football Manager 27，并加载一个单人离线存档。
2. 下载 Windows x64 的 `Fm27Editor.exe`。
3. 运行程序，点击 **Load Game** 连接当前游戏进程。
4. 点击主窗口工具栏的齿轮 **Settings**，将 Language 设为 **简体中文**。
5. 先用只读页面确认球员、俱乐部和数据加载正常，再进行编辑。

程序不会修改 FM 游戏安装目录中的文件。编辑器对游戏进程内存进行读写；保存前请备份存档。建议首次使用时另存一个测试存档，先测试单个球员和撤销功能。

## 已有功能范围

- 球员、职员、俱乐部、国家/地区、赛事、球场等数据浏览和编辑
- 球员属性、CA/PA、位置、合同、伤病、禁赛、关系、工作许可等
- 批量编辑、编辑历史与撤销
- 球队预设：恢复伤病、体能和士气，移除不满、禁赛，阻止退役等
- Wonderkid Academy 与 Development Speed 游戏内 Hook（具体支持范围以当前游戏版本配置为准）

本版本主要交付简体中文界面，不代表此前标记为未实现的合同必定接受、工作面试保证通过、球员对话结果控制、全局游戏速度等功能已经实现。
